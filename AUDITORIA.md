# Auditoría de ejercicio 4

## Objetivo
Revisar la estructura inicial del proyecto y detectar fallos por prioridad de corrección.

### Errores Críticos
- [ ] La página no tiene una estructura semántica completa: falta una etiqueta `main` clara.
- [ ] No se valida la accesibilidad básica del contenido: no hay control de contraste ni textos alternativos cuando sean necesarios.
- [ ] El archivo `script.js` se ejecuta sin comprobar si el DOM está listo en el momento correcto.

### Errores Graves
- [ ] El documento no incluye una meta descripción útil para SEO y accesibilidad.
- [ ] El diseño no presenta una jerarquía visual clara entre títulos, texto y contenido principal.
- [ ] La interactividad está muy limitada, por lo que la página parece incompleta.

### Errores Medios
- [ ] La tipografía base es muy simple y no tiene una escala visual cuidada.
- [ ] Falta un espaciado más consistente entre secciones y elementos.
- [ ] La presentación no aprovecha bien el espacio disponible en pantallas pequeñas.

### Errores Leves
- [ ] El archivo no tiene comentarios que expliquen la estructura o el propósito del código.
- [ ] El código CSS podría estar mejor organizado con comentarios por secciones.
- [ ] El nombre del ejercicio es muy genérico y podría mejorarse para mayor claridad.

## Observación general
El proyecto tiene una base funcional, pero requiere correcciones de prioridad antes de considerarse terminado.
